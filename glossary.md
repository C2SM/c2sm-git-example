# Glossary

Terms and abbreviations that come up around C2SM.

> alphabetical list, so two pull requests touching neighbouring letters will conflict. That is
> intentional — resolving it is part of Exercise 8.
>
> Keep the list in alphabetical order.

**C2SM** — Center for Climate Systems Modeling, a competence centre at ETH Zurich.

**CESM** — Community Earth System Model, a fully coupled Earth system model developed at NCAR.

**CI** — Continuous Integration. Automated checks that run on every proposed change.

**COSMO** — A limited-area weather and regional climate model, largely superseded by ICON.

**CSCS** — Swiss National Supercomputing Centre, in Lugano, where much C2SM computing happens.

**EXCLAIM** — An ETH Zurich project targeting kilometre-scale climate simulation on GPUs.

**ExtPar** — Tool generating external parameter files (topography, land use, soil) for models.

**GPU** — Graphics Processing Unit. Increasingly the workhorse of climate simulation.

**ICON** — ICOsahedral Nonhydrostatic model, the main modelling framework used at C2SM.

**LFS** — Large File Storage, a Git extension that keeps big files outside the repository.

**NetCDF** — Network Common Data Form, the standard file format for gridded climate data.

**Spack** — A package manager for supercomputers, used to build models reproducibly.
