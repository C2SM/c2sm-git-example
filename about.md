# About C2SM

The **Center for Climate Systems Modeling (C2SM)** is a competence centre at
[ETH Zurich](https://ethz.ch). It brings together research groups at ETH Zurich and partner
institutions that work on climate and weather modelling, and gives them shared technical support
that would be inefficient for each group to maintain alone.

## What the core team does

C2SM's executive office employs scientific programmers whose work is spread across:

- tasks requested by the associated working groups;
- maintaining the models, tools and datasets the community depends on;
- day-to-day user support;
- contributing to large projects such as [EXCLAIM](https://exclaim.ethz.ch/) and
  [NCCR CLIM+](https://nccr-climplus.ch/);
- organising workshops and technical training, including the Git courses.

## Getting access

Support and shared resources are organised through the
[C2SM GitHub organisation](https://github.com/C2SM). Members create a GitHub account, request
access to the organisation, and can then submit tasks and reach the supported models and tools.
