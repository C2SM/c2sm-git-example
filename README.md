# C2SM Git Example

A small collection of Markdown pages about [C2SM](https://c2sm.ethz.ch), the Center for Climate
Systems Modeling at ETH Zurich.

> [!NOTE]
> **This repository exists so that people can practise on it.** It is the working example for
> Exercise 8 of the [Git: Next Steps](https://github.com/C2SM/git-course/tree/main/advanced)
> course, and it is also used as a submodule in Exercise 2. Nothing here is authoritative —
> for real information about C2SM, see the [C2SM User Landing Page](https://c2sm.github.io).
>
> Feel free to open issues and pull requests. That is the entire point.

## Contributing

Please read [CONTRIBUTING.md](CONTRIBUTING.md). The short version:

1. Open an issue describing what you want to change.
2. Fork this repository and create a branch.
3. Make your change and open a pull request that references the issue.
4. Wait for the automated checks, then ask someone for a review.

Every pull request is checked automatically for broken links and trailing whitespace.
