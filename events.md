# Events

C2SM organises workshops and technical training for its community.

## Git courses

Two courses make up the **C2SM Git Courses**, run annually:

- **Git: First Steps** — an introduction for people who have never used Git. Commits, branches,
  merge conflicts, remotes.
- **Git: Next Steps** — for anyone who has the basics. Part 1 covers the commands beyond them
  (history, submodules, cherry-pick and rebase, stash and worktree, hooks, large files); Part 2
  covers collaborating through a web interface (issues, forks, pull requests, review).

Material for both: <https://github.com/C2SM/git-course>

**This repository is the practice ground for Git: Next Steps.** If you are on the course, you are
in the right place.
