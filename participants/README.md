# Participants

One page per person who has worked through the Git course using this repository.

## Add yourself

Create a file named after your GitHub username, for example `participants/octocat.md`, and use
this as a starting point:

```markdown
# Your Name

- **GitHub:** [@your-username](https://github.com/your-username)
- **Group or institution:** where you work
- **Working on:** a sentence about what you do

Something you learned on the course that you did not know before.
```

Then commit it on a branch and open a pull request. Because everyone edits a **different** file,
these pull requests never conflict with each other — unlike [glossary.md](../glossary.md), which
is shared on purpose.
